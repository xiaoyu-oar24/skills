### 3.1 🔴 P0 — 影响 AI 正确识别与执行

#### 问题 1：`uniapp-wechat-scaffold` 触发条件章节缺少显式 TRIGGER/SKIP 标记

| 维度 | 内容 |
|:---|:---|
| **位置** | `skills/uniapp-wechat-scaffold/SKILL.md` 第 17-20 行，🎯 触发条件章节 |
| **现象** | 正文触发章节仅写自然语言描述，**未重复** `description` 中的 `TRIGGER when:` / `SKIP:` 关键词标记。其他 7 个技能均在正文触发章节显式重复了 TRIGGER/SKIP，唯独本技能缺失 |
| **规范依据** | §3.1 "🎯 触发条件 (Trigger Conditions) — 明确 AI 在何种场景下激活" + §2.4 "TRIGGER/SKIP 约定" |
| **影响** | AI 在正文语义匹配触发关键词时可能漏触发；跨工具兼容性下降（Cursor/Windsurf 依赖正文关键词注入） |
| **修复建议** | 在 🎯 触发条件章节补充显式 `**TRIGGER when**:` 和 `**SKIP**:` 标记，与 description 中的触发词对齐 |

**当前写法**：
```markdown
## 🎯 触发条件
- 当用户要求创建基于 Uniapp 或微信小程序的初始前端项目架构时
- 当用户输入 `/uniapp-wechat-scaffold` 或要求"初始化前端项目"...
- **SKIP**：用户正在讨论现有业务逻辑...
```

**建议写法**：
```markdown
## 🎯 触发条件
- **TRIGGER when**:
  - 用户要求创建基于 UniApp 或微信小程序的初始前端项目架构时
  - 输入 `/uniapp-wechat-scaffold` 或要求"初始化前端项目"、"新建空白 uniapp 项目"、"创建微信小程序脚手架"时
- **SKIP**: 用户正在讨论现有业务逻辑，或当前目录已存在完整的 uniapp 项目结构
```

| 维度 | 内容 |
|:---|:---|
| **位置** | `skills/uniapp-wechat-scaffold/SKILL.md` 第 24 行，⚙️ 依赖与先决条件 |

### 3.2 🟡 P1 — 影响跨工具一致性与执行精度

#### 问题 3：`docs-layout-quadrant` 护栏数量超限（11 条 > 8 条上限）

| 维度 | 内容 |
|:---|:---|
| **位置** | `skills/docs-layout-quadrant/SKILL.md` 第 210-222 行，⛔ 行为护栏章节 |

| **规范依据** | §3.4 "护栏不超过 8 条 — 超过后 AI 注意力衰减，后半段形同虚设" + §5.2 "护栏膨胀" |
| **影响** | AI 注意力集中在前 3-5 条，后半段（如"索引同步不可跳过"、"内联降级允许"）形同虚设 |
| **修复建议** | 合并同类项后精简到 ≤ 8 条。建议合并：① "禁止日期前缀"与"优先中文命名"可合为一条命名规范护栏；② "规则文件注入标记不可损坏"与"规则文件注入须有授权"可合并；③ "内联降级允许"是正向授权非护栏，应移出护栏章节 |

1. 禁止日期前缀
2. 必须使用相对路径
3. 禁止散落文档
4. 保护入口文件
5. 规则文件注入标记不可损坏
6. 规则文件注入须有授权
7. 必须使用 git mv 保留 Git 历史
8. 索引同步不可跳过
9. 删除/批量移动前需确认
10. 禁止空壳文档
11. 内联降级允许

**建议精简为 8 条**：
1. 🚫 禁止日期前缀 + 优先中文命名（合并）
2. 必须使用相对路径
3. 禁止散落文档 + 保护入口文件（合并）
4. 规则文件注入标记不可损坏 + 注入须有授权（合并）
5. 必须使用 git mv 保留 Git 历史
6. 删除/批量移动前需确认
7. 禁止空壳文档
8. 索引同步不可跳过

> 注："内联降级允许"为正向授权，建议移入工作流相关章节或删除。

## 六、审计方法说明

本次审计采用以下方法：

1. **静态扫描**：通过脚本检查所有 SKILL.md 的 Frontmatter 字段完整性、description 长度、YAML 危险字符、正文章节结构
2. **规范对照**：逐条对照 `docs/guide/AI规则与技能统一编写规范.md` 中的强制性约束（红线）与建议
3. **跨工具分析**：基于各主流 AI 工具的官方文档与已知行为，评估技能在不同工具下的兼容性
4. **人工复核**：对脚本标记的异常点进行人工确认，避免误报
