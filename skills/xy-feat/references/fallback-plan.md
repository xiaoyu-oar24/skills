# xy-feat 降级流程：阶段 2（规划分解）

> 本文件在 L1/L2 未使用独立规划技能时按需读取，授权沿用正文规则。**档位适配**：L0 已合并到阶段 1 简短说明，不再加载本文件；L1 只列精简任务清单并更新 specs 状态，不套用全量任务卡；L2 档按下方流程写入 `aidocs/plan/<功能名>-plan.md` 与 `aidocs/tracking/<功能名>.md`。`aidocs/tracking/<功能名>.md` 的格式以本文件模板为准。

## 2.1 刷新上下文

使用阶段 1 的设计上下文；文件发生变更或上下文缺失时再读取 `aidocs/specs/<功能名>-design.md`，不机械重复读取。

## 2.2 任务拆解原则

- **每任务一个可验证交付物**：写测试/静态校验 → 验证失败 → 写实现 → 验证通过；只在已有对应授权时执行原子提交，不把机械的 2-5 分钟时长作为拆分标准
- **任务自包含**：每个任务产出可独立测试的交付物
- **边界清晰**：一个评审者应当可以"批准任务 A 但拒绝任务 B"
- 按"后端 → 前端 → 集成"的顺序排列任务

## 2.3 L2 每个任务卡片必须包含

- **Files**：创建/修改哪些文件（精确路径）
- **Interfaces**：消费哪些上游产出、产出哪些下游依赖（精确签名）
- **Steps**：逐步操作列表，每步包含实际的代码块和命令（禁止 TBD/TODO）
- **Expected**：每步的预期结果（如 "FAIL with 'function not defined'" 或 "FAIL tsc type error"）

## 2.4 规划文档输出

**仅 L2 档**将规划结果写入 `aidocs/plan/<功能名>-plan.md`；L1 档随设计一次性呈现精简清单，不写入 plan/tracking 文件、不等待重复确认：

````markdown
# [功能名] 实施计划

> **目标：** [一句话描述]

**架构：** [2-3 句技术方案概述]

**技术栈：** [关键技术和库]

## 全局约束
[从 spec 中提取的跨任务约束 — 版本要求、命名规则、平台要求等]

---

### Task 1: [组件名]

**Files:**
- Create: `src/path/to/file.ts`
- Test: `tests/path/to/test.ts`

- [ ] **Step 1: 编写失败测试/静态断言**
```typescript
test('具体行为描述', () => { ... });
```
- [ ] **Step 2: 验证失败** → `pytest tests/path -v` → Expected: FAIL
- [ ] **Step 3: 编写最小实现** → 仅通过测试所需的最少代码
- [ ] **Step 4: 验证通过** → Expected: PASS
- [ ] **Step 5: 可选提交** → 仅有本地提交授权且适用检查通过时提交任务文件，否则保留工作区改动
````

## 2.5 创建进度跟踪

**L1 快照出口**：规划自审通过后，把任务状态和可查证的授权来源写入 `aidocs/specs/<功能名>-design.md` 的 `## Execution State` 节；后续每次任务完成或阶段切换同步刷新该节。

**仅 L2 档**同步创建 `aidocs/tracking/<功能名>.md`，初始化所有任务卡片状态为 `⏳`；L1 档在对话内维护同一清单（状态标注 ⏳/🔄/✅），不落盘：

```markdown
# 状态总览
创建日期：YYYY-MM-DD | 当前阶段：阶段 2 | 模式：TDD/VDD

# 任务卡片
- ⏳ [后端] Task 1: 创建 API 路由
- ⏳ [后端] Task 2: 数据校验逻辑
- ⏳ [前端] Task 3: UI 组件
- ⏳ [前端] Task 4: API 联调
- ⏳ [集成] Task 5: 端到端验证
```

## 2.6 自审规划与授权核对

自审清单：
- **Spec 覆盖**：spec 中的每个需求是否都能指向一个 task？
- **占位符扫描**：是否有 TBD/TODO/"添加适当的错误处理"等占位？
- **类型一致性**：后面 task 引用的类型/签名是否与前面 task 定义的完全一致？

**出口**：自审通过且实现范围已有授权时进入阶段 3。仅未决重大取舍或新增范围需要确认；设计和计划一起呈现，避免分两轮审批。

**Git 权限独立**：记录已有提交授权及适用范围；批准方案不自动授权 Git 写操作。未授权时继续实现和验证，保留工作区，到阶段 7 按用户实际交付目标处理。
